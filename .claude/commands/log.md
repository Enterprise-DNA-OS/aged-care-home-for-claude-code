---
description: A dated progress note on a resident: a handover point, a GP visit, a family call, a behaviour, a clinical observation.
---

Run `npm run ac -- log <resident> "note" --kind=note|handover|gp|family|clinical|behaviour --by=<staff code>`.

Write the note in the operator's words, in plain past tense. If the note describes an incident (a fall, an injury, an allegation, a resident missing), say so and offer `/incident`: a note is not an incident record.
