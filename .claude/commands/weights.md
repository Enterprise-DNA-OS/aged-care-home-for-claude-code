---
description: Residents with unplanned weight loss of 5% or more over about three months, or lower every month. Record a new weight.
---

- Who is losing weight: `npm run ac -- weights` (`--all` for everyone, `--loss=3` for an earlier warning).
- A new weight: `npm run ac -- weigh <resident> <kg> [--date] [--planned]`. Use `--planned` only when the GP or dietitian has set a weight loss goal.

For anyone flagged, the action is a GP and dietitian review and weekly weights. Check the latest notes on `/resident` before suggesting anything else.
