1. Run `npm run ac -- resident <code or name> --json`. If more than one matches, list them and ask which.
2. Write a short summary first: who they are, where they live, what has changed in the last month, anything overdue.
3. Then the sections that have something in them. Leave out empty ones.
4. Never answer a question about a resident from memory. If it is not in the record, say so.
