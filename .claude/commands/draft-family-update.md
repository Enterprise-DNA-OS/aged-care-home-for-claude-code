---
description: Draft a short update to a resident's representative after a change: a fall, a hospital stay, a new medicine, a care plan review.
---

1. Run `npm run ac -- resident <code> --json` and read the last month.
2. Write `drafts/family-update-<code>.md` to the representative: what happened, what the home did, what changes now, who to call. Warm and plain.
3. If the change is an incident with harm, the update is part of open disclosure: say sorry for what happened without assigning blame, and record it with `npm run ac -- disclose <ref>` once it is given.
4. Never send it.
