---
description: Draft the invitation to a case conference and the agenda, from the resident's record.
---

1. Run `npm run ac -- resident <code> --json`.
2. Write `drafts/case-conference-<code>.md`: the invitation to the representative (date to be agreed, interpreter if the alerts say so), and an agenda from the record: changes since the last review, weight, falls, wounds, restrictive practices and their consent, medication changes, what the resident enjoys, the advance care plan.
3. After the meeting, record it with `/review --conference`.
